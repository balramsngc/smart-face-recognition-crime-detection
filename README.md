Smart Face Recognition and Crime Detection System

Project Overview

An educational Python computer vision project exploring face recognition for surveillance applications, including facial image processing and masked-face identification.

Features

- Face encoding and recognition
- Facial image processing
- Masked-face testing
- Database integration
- Web interface

Technologies Used

- Python
- OpenCV
- Face recognition libraries
- HTML
- SQLite (if configured in the project)

Project Modules

- "app.py" — Application module
- "main.py" — Main program
- "add_criminal.py" — Record registration
- "database.py" — Database operations
- "encode_faces.py" — Face encoding
- "face_loader.py" — Image loading
- "match_face.py" — Face matching
- "recognize.py" — Recognition module
- "index.html" — Web interface

Disclaimer

This project is for educational purposes. Face recognition can produce false matches and must not be treated as proof of criminal activity. Use only authorized, consented demo data.

Setup

Install the dependencies listed in "requirements.txt", configure the required database and image paths, and follow the application's entry-point instructions.
